# Frozen threshold-resolution control

The completed timely-target study found a positive primary target effect under
matched-early mixtures but a nonpositive point estimate under the original
common deterministic budget-one policy. The same coarse grid underlies both.
This follow-up asks whether finer threshold resolution recovers the target gain
without randomized threshold mixtures. It reuses completed scores; no new fit,
new observation time or test access is allowed.

The machine-readable plan fixes all 1,002 candidates: silence, the original
101 numeric thresholds retained bit-for-bit, and nine log-spaced interior values
in each adjacent interval. Common and region-specific deterministic policies
use the original budget, hit objective and cost/high-threshold tie rules. All
72 early heads (four families, three seeds, three events, two windows) must be
jointly frozen before later evaluation. Original coarse-grid early counts must
reproduce exactly. All prior policy results remain unchanged.

The primary is timely LeagueEWS minus cumulative LeagueEWS in 10–30-second macro
recall under the dense common rule at budget one. Report burden with its paired
interval, all events, all seeds and both regions. Also report all four budgets,
both lead windows, dense regional rules, original policies, TCN target effects,
and differences of target effects across architectures and threshold grids.
Positive mean recall alone does not establish equal cost or practical promotion.
No gate is relaxed after results. Increasing the early candidate set can improve
early selection through overfitting; later gains are not guaranteed.

All uncertainty uses the same 2,000 whole-match region-stratified draws and fixed
seed means as the previous study. Rows, repeated seeds, policies and budgets are
not independent matches. Intervals are conditional and pointwise; calibration
has already been inspected, making this adaptive exploratory evidence. There
is no new confirmation sample and patch 16.17 stays sealed.

The original common/regional policies and whole-match mixtures are controls;
new policies must pass independent replay on every later match at budget one,
plus every selected threshold on a fixed match sample. Freeze source and analysis
before execution. Save all regional overruns, negative results and aggregate
counts, while keeping match arrays, scores and model binaries private.
