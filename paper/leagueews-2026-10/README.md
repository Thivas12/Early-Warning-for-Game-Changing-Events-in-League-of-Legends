# LeagueEWS controlled evaluation paper

[Read the working paper](leagueews-working-paper.pdf). The source is
[`docs/leagueews-paper-draft.md`](../../docs/leagueews-paper-draft.md); the PDF
adds source-derived figures and the saved-model runtime appendix.

This is an exploratory development paper, not an accepted publication or a
confirmed new method. All three League event types and negative results remain
in scope. The original legacy-audit paper at `paper/main.tex` is preserved.

Use the [reproduction guide](../../reports/publication-package-2026-10-07/reproduce.md)
to regenerate the PDF, figures and two-page project brief from public aggregate
artifacts. [AI assistance and pending human verification](../../docs/ai-usage.md)
are disclosed. The [one-time confirmation design](../../docs/leagueews-confirmation-protocol.md)
records the remaining publication work without opening the test patch.
